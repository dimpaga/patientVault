| D-016 | 2026-10-23 | `app.security.mfa.required=false` allows login without a second factor for users who have not enrolled, but there is **no enrolment from Settings** yet. | MFA is mandatory by default; an enrolment page in Settings can be added if the optional mode is ever needed. |
| D-017 | 2026-10-23 | Lockout: 5 consecutive failures lock for 15 min, each further block of 5 doubles it up to 8 h (`app.security.lockout.*`). | D-018 | 2026-10-23 | Audit records for failed logins use actor `ANONYMOUS` and never the attempted username. | Users sometimes type their password into the username field; it must not reach logs. |

| D-021 | 2026-10-23 | The request cache remembers only HTML GET navigations (not htmx partials, assets or favicon requests). | Otherwise the browser's pre-login favicon request becomes the post-login redirect target. |
| D-022 | 2026-10-23 | Deferred from step 2: notification-email setting and reminder preferences (step 8), PWA manifest/service worker (step 9), Spring Modulith/ArchUnit verification (with tests). | Features that depend on later modules, or on the test phase. |

| D-052 | 2026-10-24 | Local times inside a spring-forward gap move forward; times in a fall-back overlap take the first offset. The form uses `datetime-local` interpreted in `app.timezone`. | Deterministic, documented behaviour for the two ambiguous hours of the year. |
| D-053 | 2026-10-24 | Rescheduling replaces PENDING reminders with newly planned ones and leaves SENT/FAILED rows as history; cancelling or completing cancels PENDING ones.
